# Студия креатора (iOS)

Личное приложение Mathias: запись на фронтальную камеру с телесуфлёром. Спецификация: https://claude.ai/artifact/YGrDsSPEUYQWHAs6yyiE18

## Установка на iPhone (бесплатный Apple ID)

1. Установи Xcode из App Store и один раз открой его.
2. Двойной клик по `setup.command`: создаст проект и откроет Xcode. В выводе должно быть `PROJECT: OK`.
3. В Xcode: Settings → Accounts → «+» → Apple ID, войди своим аккаунтом.
4. Слева выбери проект CreatorStudio → таргет CreatorStudio → вкладка Signing & Capabilities → Team: твоё имя (Personal Team).
5. Подключи iPhone кабелем, выбери его вверху в списке устройств, нажми ▶ (Run).
6. На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить (телефон перезагрузится).
7. Настройки → Основные → VPN и управление устройством → твой Apple ID → Доверять.

Подпись бесплатного аккаунта живёт 7 дней. Потом снова шаг 5.

## Тесты

В Xcode: Product → Test (⌘U).

## Что уже умеет (этап 1)

- Фронтальная камера в лучшем формате устройства (до 4K, до 60 fps), HEVC, звук AAC 48 кГц.
- Суфлёр узкой колонкой у камеры, скорость и размер текста, линия чтения, подмотка пальцем.
- Пауза одной кнопкой останавливает и запись, и текст. Play после отсчёта продолжает в тот же файл, пауза вырезается.
- Кнопка «повтор» ставит метку, после записи список меток.
- Сетка безопасной зоны Reels.
- Сохранение в галерею.

## Дизайн

Токены один в один с razberemsya.de: `CreatorStudio/Design/Tokens.swift` (цвета светлой и тёмной темы, скругления, шрифт Inter, вшит, лицензия OFL). В настройках: тема «Светлая / Тёмная / Система» и размер текста «Обычный / Крупный», как на сайте.
